 ## 使用技術
 HTML / CSS / JavaScript 
 ## 制作内容
- コーディング
- レスポンシブ対応
- アクセシビリティを意識したマークアップ
## 工夫したこと
GoogleビジネスプロフィールやSNSプロフィール欄から訪問したユーザーが、院の特徴やサービス内容を短時間で理解し、問い合わせにつなげられるサイトを想定しました。  
デザインはAIを活用していますが、出力されたコードを使用せず、スマートフォン・タブレット・PCの各画面サイズで修正やレイアウト調整を行いやすいよう、
HTML・CSSを一から実装しました。  
第三者が修正・運用を行うことを想定し、可読性・保守性を重視したコーディングを心掛けました。
掲載画像は『O-DAN』、人物画像は『いらすとや』で提供されている素材を使用し、画像容量の大きいものは表示の高速化を考慮してWebP形式へ変換しています。
